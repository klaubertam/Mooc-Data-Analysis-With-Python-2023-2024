# Data Analysis with Python 2023-2024

My solutions for the Data Analysis with Python MOOC by the University of
Helsinki (MOOC.fi). The course covers NumPy, pandas, Matplotlib and SciPy for
data cleaning, grouping and summary statistics, and later parts move into
machine learning (regression, classification, clustering).

Each folder contains the exercise solution and its required input files.

**Status:** in progress, currently on part 5. I add each part as I finish it.
